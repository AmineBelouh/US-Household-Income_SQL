# 🏠 US Household Income Analysis

This project uses **MySQL** to clean and explore a U.S. household income dataset. The project includes data cleaning to improve data quality and exploratory data analysis (EDA) to examine geographic and income-related patterns.

## 📁 Project Files

- 📄 [Data_Cleaning.sql](./Data_Cleaning.sql)
- 📄 [EDA.sql](./EDA.sql)
- 📊 [USHouseholdIncome.sql](./USHouseholdIncome.sql)
- 📊 [USHouseholdIncome_Statistics.sql](./USHouseholdIncome_Statistics.sql)

## 📈 Analysis

### Data Cleaning
- Removed duplicate records.
- Corrected inconsistent values in the `State_Name` column.
- Populated missing values in the `Place` column.
- Standardized values in the `Type` column.

### Exploratory Data Analysis (EDA)
- Compared land area and water area by state.
- Explored mean and median household income by state and city.
- Explored mean and median household income by location type (e.g., Borough, Town, Village).
